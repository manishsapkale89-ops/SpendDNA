# 💳 SpendDNA - Financial Analytics & Spending Intelligence

SpendDNA is a **Python-based financial analytics engine** that processes bank transaction data to generate meaningful spending insights. It performs transaction cleaning, expense categorization, vendor identification, trend analysis, anomaly detection, and behavioral profiling to help users better understand their financial habits.

---

## 📌 Key Features

* **Transaction Preprocessing**: Cleans raw transaction data, removes duplicates, standardizes dates, and converts currency values into numeric format.
* **Credit & Debit Analysis**: Separates income and expenses while calculating total credits, total debits, net financial change, and savings rate.
* **Vendor Identification**: Identifies the most frequently used merchants and ranks them based on transaction count and spending.
* **Expense Categorization**: Classifies transactions into categories such as E-Commerce, Food Delivery, Investments, Restaurants, and Other Discretionary expenses.
* **Executive Financial Summary**: Generates a detailed overview of credits, debits, savings rate, transaction volume, and vendor statistics.
* **Monthly Spending Trends**: Analyzes month-wise expenditure to identify changes in spending behavior over time.
* **Time-of-Day Analysis**: Detects peak spending hours for categories such as food delivery and café purchases.
* **Anomaly Detection**: Uses **Z-Score statistical analysis** to identify unusually large transactions within each spending category.
* **Behavioral Profiling**: Assigns spending archetypes (e.g., **Shopaholic**, **YOLO Spender**) based on financial behavior.
* **Insight Generation**: Produces actionable financial recommendations and spending summaries in a professional command-line report.

---
